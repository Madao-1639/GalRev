# krkrz + M2「MDF」 —— 剧本文本模型

剧情不是 KAG 的 `.ks`，而是编译进 **PSB** 的结构化对象（外壳见
[file-formats.md](file-formats.md) §2）。本文说明：哪些字段是文本、哪些是内部键、
替换文本时必须同步维护什么。

## 1. 场景（`root["scenes"][i]`）

| 键 | 含义 | 可翻译 |
|---|---|---|
| `label` | 场景标签（`*start`、`*normal`、`*replay_xx` 等） | ❌ 跳转目标 |
| `firstLine` | 该场景第一行的全局行号 | ❌ |
| `lines` | 命令流（`envupdate` / `update` / `wait` / `bg` / `anm_*`…），含资源名与内部键 | ❌ |
| `texts` | 对白行数组 | ✅ 见 §2 |
| `selects` | 选项数组（有分支的场景才有） | ✅ 见 §4 |
| `nexts` / `preevals` / `postevals` | 跳转与标志位（`f.xxx = 0`、`sf.clear_xx = 1` 之类 TJS 片段） | ❌ |
| `title` / `spCount` / `version` / `selectInfo` | 元数据（`title` 常为空串） | ❌ |

## 2. 对白行（`scene["texts"][i]`，5 元）

```
[0] speaker     说话人显示名（string|null）                       ✅ 可翻译
[1] pages[]     分页数组                                          见下
[2] attrs[]     每页属性 dict：name=语音角色键, pan, type, voice=语音文件名   ❌
[3] flag        行级标志（语料中恒为 64，【跨作需重验】）           不动
[4] {data, env, …}  命令容器（转场 / 立绘 / BGM 等）                 ❌
```

分页两种形态：

```
3 元：[voice_gate|null, text, length]
5 元：[voice_gate|null, text, length, text_plain, text_plain]
```

| 字段 | 含义 | 处理 |
|---|---|---|
| `[0]` | **逐页**说话人覆盖（`？？？`、`全体女生` 之类），非空时覆盖行首 speaker | ✅ 可翻译 |
| `[1]` | 正文；换行是字面两个字符 `\` `n`；行内标记见 §5 | ✅ 翻译目标 |
| `[2]` | `length`，口径见 §3 | ⚠️ 替换后必须重算 |
| `[3]` | `text_plain`：去掉 `\n` 的同一段（`[3]`/`[4]` 正常共用一个字符串槽） | 见 §6 |

同一份数据里**两种分页形态可以并存**（语料中约 7:3）；没有 `text_plain` 不代表数据缺失。

## 3. `length` 字段的两种口径

| 来源 | 口径 | 判据 |
|---|---|---|
| 日文原版 + 民间汉化工具链 | **原始长度**：行内标记与 `\n` 全算 | 与 `UTF-16 码元数`逐条一致 |
| 官方本地化工具链 | **显示长度**：删掉 `%NNN;`、`#RRGGBBAA;`、`#;`、`\k`、`\p` 后再算 | 含标记的页全部符合；无标记时两派等价 |

例：`%205;磅──！！！` → 官方记 `6`，汉化侧同句记 `11`。

规则：**回写哪一版就按哪一版的口径算，同一批产物不得混用**。字段只影响自动/快进节奏，
写错不崩；建议封装成单一函数（库：`galrev.krkr.scn.page_length`，实现显示长度口径），
并在校验脚本里对两派分别计数。

## 4. 选项（`scene["selects"][i]`）

```
{ render:1, selidx:0, storage:"…", target:"*start", text:"是" }
```

- `text` 是选项文本 → ✅ 可翻译。
- `button: "yes"|"no"` 形态没有 `text`，按钮文字来自 UI 层（`.tjs`），不在脚本里。

## 5. 行内标记（必须原样保留）

| 形式 | 例子 | 作用 |
|---|---|---|
| `%NNN;` | `%205;嘭！！！` | 字符/语音标记（角色或特效索引） |
| `#RRGGBBAA;` | `#000033ff;` | 文字着色 |
| `#;` | `……#;也要` | 颜色复位 |
| `\n`（字面反斜杠+n） | `——是啊。\n嘴唇…` | 强制换行 |
| `\k` / `\p` | `…\k%123;不是…` | 点击等待类标记 |
| `\\` | `anim\\bg\\img` | 转义反斜杠（多见于开发备注脚本） |

匹配/翻译时把它们当**不参与翻译的记号**：数量与相对顺序必须守恒。

## 6. 回写不变量

1. `length` = 目标版口径（§3），逐条重算
2. 行内标记数量与相对顺序不变（§5）
3. 目标版是 3 元分页时只写 `text`；沿用 5 元分页才需要自己补 `text_plain`
4. 字符串槽数量不变 ⇒ 可用字符串池级重写（[file-formats.md](file-formats.md) §3.5）；
   要改 `length` 必须走完整对象图序列化器
5. 改写后回读校验：`length == page_length(text)`、正文与预期一致、标记数一致

## 7. 跨版本对齐（同一引擎不同发行版）

- 对齐键用 `(脚本名, 场景 label, 行号, 页号)`：两版脚本结构通常同构，可直接逐句对位；
  语料中两版共有脚本的**场景条数零差异**，无需模糊对齐
- 脚本名取自 PSB 的 `root["name"]`（加密归档里没有真名），**不要用文件名**
- 差异面集中在：新增/删减的路线脚本、`length` 口径、引号风格（`「…」` vs `“…”`）、
  以及部分出版社改写过的段落 —— 匹配阶段要把这四类分开统计
- 库：`galrev.krkr.scn.ScnFile`（`iter_messages()` / `iter_selects()` / `rebuild()`）
