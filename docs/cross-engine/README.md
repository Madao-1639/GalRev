# 跨引擎转换（Willplus → AdvHD）

本卷研究 Willplus 旧引擎（WSC）与 AdvHD 系引擎（WS2）之间的**忠实转换**：两代引擎二进制不通用（归档、脚本混淆、指令集全部不同，原版资源解包后不可直接塞进 Steam 版），但内容层面完全对位——WSC 解密后的文本、资源引用与演出顺序与 Steam 版一一对应，可作权威信源。**语音 OGG 是唯一可直接复用的资源**（其余资源在二进制层面都须重制或重命名补入）。

## 两代引擎的职责对照

同一演出概念在两代脚本里的表达方式：

| 概念 | 原版 WSC | Steam WS2 |
|---|---|---|
| 绑定图 → 层 | `0x46`/`0x48` **直接带资源名** | `0x33`/`0x34`（槽名 + 文件名） |
| 位置 | 在 `0x46`/`0x48` **内联**（x/y，可预设索引） | **独立** `0x46`（通道名 + cfg + 4×f32） |
| 选帧（立绘） | 在 `0x48` 内（一条指令 = 一张完整图） | `0x39`（PNA 记录下标） |
| 解绑 | 无此概念（位号覆盖即换图） | `0x37` |

即：转换的核心动作是把 WSC **内联的「绑定 + 位置」**拆成 WS2 的「绑定 + 独立定位」。原版立绘是单张完整 PNG（差分 = 换文件），Steam 立绘是 PNA 子图层（大图 + 表情补丁，由 `0x39` 选记录），两者的表达力不同。

两侧的引擎侧知识见 [../engines/willplus/wsc-opcodes.md](../engines/willplus/wsc-opcodes.md) 与 AdvHD 卷。
